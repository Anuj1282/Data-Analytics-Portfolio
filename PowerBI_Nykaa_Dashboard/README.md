# 📊 Nykaa Sales Dashboard | Power BI

## Project Overview
Developed an interactive Power BI dashboard to analyze sales performance, customer trends, and product insights for a retail beauty and cosmetics business.

## Tools Used
- Power BI
- Excel
- Data Visualization
- Business Intelligence

## Dashboard Features
- Sales Performance Analysis
- Product Category Analysis
- Revenue KPIs
- Customer Insights
- Interactive Filters and Slicers

## Key Insights
- Identified top-performing product categories
- Analyzed revenue contribution by segments
- Tracked sales trends and KPIs
- Improved decision-making through visual analytics
