# 📊 E-Commerce Sales Analysis using SQL

## Project Overview
This project analyzes e-commerce sales data using SQL to generate business insights on sales performance, profitability, customer behavior, and regional trends.

## Tools Used
- MySQL
- SQL
- Excel

## Key Analysis
- Total Sales & Profit
- Sales by Region
- Top Products
- Customer Analysis
- Profit Analysis

## SQL Concepts Used
- GROUP BY
- ORDER BY
- Aggregate Functions
- Subqueries
- Window Functions
- Views

## Business Insights
- Identified top-performing products
- Analyzed regional sales trends
- Ranked top customers
- Evaluated profitability
